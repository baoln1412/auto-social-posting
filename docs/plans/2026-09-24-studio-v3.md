## 1. What the owner said, and what the screenshots show

Owner, 2026-09-23, after seeing v2 on :3001: *"looks somewhat ok but I like the way we currently
show the posts on Desoul Posting more, can we use it as our library? Polish the demo steps to be
clearer. The steps to fix the post images and video seem missing compared to our ASP. The UI is not
good — honestly I want almost 100% of that UI/UX except our features/functions and brand guideline.
The features are somewhat enough (research more what should go in, for my need and general needs),
but the UI/UX is still really bad."* Three answers were then fixed with the owner: **light only, no
dark mode** (brand rule; research the best light UX for the brand) · **library = the post lake,
one PostCard per post** · **polish both** the run page's step screens and the first-run tour.

What the screenshots show (`docs/plans/mock-v3/pairs/now-*.png` beside `docs/plans/ref/*`):

| Cause | Evidence in v2 | Reference does instead |
|---|---|---|
| Mono caps used for labels and headings | `/STUDIO · TẠO MỚI`, `NGUỒN TỰ ĐỘNG`, `KHO BÀI CỦA KÊNH` | sentence-case labels; mono only for counts |
| No icons anywhere | nav is eight words | icon on every nav row, section, tab |
| No filled call to action | nothing green on the create page | one green `Tạo video mới` |
| Empty tiles | `Kết quả gần đây` is six dashes; library thumbnails are dashes | a real frame in every tile |
| The preview is a black box | kit canvas = black + a card whose text is cut at both edges | background + card + karaoke subtitle |
| Raw label + select forms | kit editor's right column | icon + title + helper; radio cards; toggles |
| Typed wordmark | sidebar says `DESOUL` in Source Sans (brand rule 3 forbids it) | (SPA already uses `wordmark.png`) |
| Pen + shadow on everything equally | lists, chrome and cards all outlined | depth only on raised, interactive things |

The research behind the fixes is in `docs/plans/mock-v3/research-ux.md` (patterns, with URLs) and
`docs/plans/mock-v3/research-features.md` (features, platform limits, with URLs). Their finding
that matters most for scope: **ThreadViral is a render tool. A 1:1 copy has no destinations, no
schedule, no analytics, no failure alerts** — the things every publisher (Buffer, Later, Metricool,
Publer) treats as core, and the owner runs six pages. §7 adds that half; most of it is reuse of
components the old SPA already has.

## 3. The look — the brand, applied

`~/.claude/skills/desoul-brand/SKILL.md` + `brand.json` are the source. The mocks' `mock.css` is
the worked example; port it to `app/studio/studio.css` (imported by `app/studio/layout.tsx`,
never into `globals.css`) as classes, and keep Tailwind for layout only.

- **Surfaces.** Page `paper #F7F5F0`; raised `card #FFFEFB`; recessed `faint #F2EFE6`. **One dark
  surface exists: the stage** (`#141414`) — the phone preview, the layer canvas, the player. It is
  video, video is dark, and every light creative tool (Canva, Figma, Descript) does the same. The
  stage always sits inside a pen-outlined bezel so it reads as an inset, not a failure.
- **The line.** `border: 2.5px solid #211F19; box-shadow: 4px 4px 0 #211F19` on **raised,
  interactive things only**: cards, buttons, chips, the phone bezel, the tooltip. Never on chrome
  (sidebar, header, tabs row), never on list rows, never on text. Rows inside an outlined panel are
  not outlined again (`pen-2 #6B6455` hairline at most).
- **One accent.** `#2F6B4F` fills exactly one primary per screen plus the sidebar CTA; selected
  rows/cards get `accent-soft #E7F0E9` fill + accent border; the bottom tab strip marks the active
  tab with an accent top edge — the other tabs get `pen-2`, **not eight hues**. Amber `#B0700F` and
  red `#B3402F` mean warn and error and nothing else.
- **Type.** Baloo 2 for h1–h3 and the product's own voice (`Dựng *video mới*`); Source Sans 3 for
  everything else; **Source Code Pro only for numbers, ids, paths, codes** (`$1.84`, `6 cảnh`,
  `0:17`, `#75281757`). An eyebrow (`TỔNG QUAN STUDIO · 1/8`) may be mono caps at ≤ 11 px; nothing
  else is caps.
- **Icons.** `lucide-react`, already installed, `strokeWidth={2.25}` so they hold beside a 2.5 px
  line. Every nav row, section title, tab and empty state has one.
- **The mark.** `public/wordmark.png` + `STUDIO` set in Fredoka 700 exactly as
  `app/components/layout/AppSidebar.tsx` does for `POSTING` (copy its measured CSS); favicon
  `public/mark-18px.png`. Never the word typed.
- **Empty states** are the reference's `tv-21`: icon, one-line reason, one action. Never a dash.
- **Numbers the owner can't have** (credits) become numbers they do have: the header pill is
  `Tháng này $1.84` from `studio_runs.cost_usd` summed over the calendar month.

## 10. Traps this repo already paid for (v1 §9, v2 §9 still apply; these are new)

- **`PostCard` is a client component with its own state, hooks and modal.** Import it; wrap it;
  never fork it. It reads `process.env.NEXT_PUBLIC_STUDIO_ENABLED` for its Studio link — set it in
  `.env.local` on 3001 so the link renders, and make the redirect route before you test it.
- **A composed frame is the engine's.** `/api/video/preview` spawns `make-reel.py`; a bad-looking
  frame means a bad kit value, not a composer to patch. Change the kit; prove it with the pixel
  gate.
- **Two dark surfaces feel like two bugs unless they are one component.** The phone bezel, the
  layer stage and the player share one `Stage` component.
- **`font-mono` is a tell.** The v2 pages used it as a label style; the §2.9 test exists so no
  slice reintroduces it.
- **The old SPA's Graph calls hold the page tokens.** Publishing from Studio calls the SPA's route
  for what it already does and adds only Reels beside it; two implementations of "post a photo"
  drift by the first bug fix.
- **rtk truncates.** Any `curl` of `/api/posts` or `/api/pages` through the hook returns cut JSON
  that fails to parse; `rtk proxy curl -o file` and read the file.
- **`pgrep -fl` prints every process's environment**, keys included. `pgrep -f` or `ps -p <pid> -o
  pid,comm`.
