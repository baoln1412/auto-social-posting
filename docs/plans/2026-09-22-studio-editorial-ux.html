02The one idea: a step contract

A run is a source item moving through fetch → draft → image → reel → publish. Every step declares the same four things, so the run page is generic and AILP can adopt the shape as data.

Rules. A step writes its record on success and failure. Continue is disabled while a gate has findings — or while a declared gate never ran (checked = 0 is not a pass). Runs resume from the failed step. A channel's auto-continue switch skips the button only where the preview cost is $0.

07What transfers to AILP, honestly

The design and three data contracts: the Brand Kit schema and presets (canonical in ~/research-console/brand/kits/), the step contract, the tour spec. The React code does not transfer to a Jinja app. AILP adopts the pattern on its own stack, or its Studio moves into this app as a second engine once the cutscene pipeline is stable — a decision for then, and this plan keeps it open.
